# ft-Hochregallager-und-ft-3-Achs-Roboter
Die beiden Modelle fischertechnik Hochregallager und 3-Achs-Roboter im Kombibetrieb so wie gemeinsame Unterlagen für diese Modelle

![ft-Hochregallager-und-ft-3-Achs-Roboter](Bilder/ft-3-Achs-Roboter_mit_HRL_Lager.png)

## Projektbeschreibung
Die Kombination zeigt die beiden Modelle aus dem fischertechnik-Baukasten
„ROBO TX Automation Robots“ als Automatisierungseinheit:

* den 3-Achs-Roboter
* das Hochregallager

#### Funktion:
Das Hochregallager stellt ein ausgelagertes Teil am Umsetzer bereit und meldet dem Roboter über ein Freigabesignal, dass das Teil abgeholt werden kann.

Der 3-Achs-Roboter erkennt dieses Signal, holt das Teil ab und transportiert es zur Ablage.

Umgekehrt kann der Roboter ein Teil am Umsetzer bereitstellen. Das Hochregallager erkennt das dort abgelegte Teil über einen Sensor und lagert es automatisch ein.

Links zu den Videos, in denen die Funktionen und Bedienmöglichkeiten der beiden Modelle ausführlicher vorgestellt werden, befinden sich im Abspann dieses Videos.
